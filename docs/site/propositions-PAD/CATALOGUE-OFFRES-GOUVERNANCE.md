## Flywheel SBO (stratégie d'acquisition)

Entrée par l'expertise (Pilier 3, TJM) → confiance + révèle les Skills Gaps → Transformation par le conseil (Pilier 2, Audit Flash → STRIDE) → Standardisation par la Tech (Pilier 1, Learning App reste après la mission, revenu récurrent) → données réelles nourrissent CMT pour concevoir de nouveaux modules → PAD revend en Upskilling.
